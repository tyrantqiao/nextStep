# 今日与计划分工改版

日期：2026-10-22。范围为网页源码；未重建或发布APK。

## 页面职责

| 视图 / 步骤 | 主要内容 | 操作边界 |
| --- | --- | --- |
| 今日 | 当前训练优先；没有草稿时展示今日安排；今日已保存记录 | 确认开练前不计时，临时训练明确立即计时；补记运动单独录入 |
| 计划 | 七天安排、所选日期动作、已训练标记、每周默认计划入口 | 查看其他日期不会改变今日训练目标；没有跨日期开练按钮 |
| 单日编辑 | 已选动作参数、顺序、移除、添加动作 | 日期固定，保存只影响这一天；已有动作直接编辑，无需重走动作库 |
| 添加动作 | 最近练过 / 全部动作、搜索、部位、器械、示意 | 返回清单保留已填组数、次数、重量；不计时 |
| 每周重复确认 | 明确日期、星期、动作参数及其他日期保留规则 | 一次持久化同时保存所选日期与该星期的默认安排，失败可重试 |

沿用原localStorage键及profile、records、draft结构。没有清空或迁移已有资料。没有新增联网资源、依赖或原生桥接。按已保存日程计算每周训练目标，手动设为每周重复时不依赖个人资料中的频率字段。
