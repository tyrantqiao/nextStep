## 实现

手机依次展示今日训练、今日活动、今日记录、本周回顾。桌面使用两列：训练与活动为第一排，记录与回顾为第二排。主行动放回训练卡，保留开练、再练、续练、完成保存四种状态，不再用悬浮按钮遮挡内容。

本周回顾通过训练趋势/运动构成并列按钮切换，共用稳定高度。指标选择和当前滚动位置保留，隐藏视图不参与键盘操作或屏幕阅读。今日活动四项数字和单位对齐，继续提供热量补填和每日步数入口。原本周计划、旧链接、持久化数据和训练计算保持兼容。

## 验证

- JavaScript 语法、136 项 Node 业务回归及差异格式检查通过。
- 独立测试来源 Chromium 在 320×568、390×844、1280×900 检查空首页、已保存、休息日、训练中、暂停、等待保存六种状态；整页无横向溢出，数字与单位对齐，主行动可在首屏看到。
- 三种尺寸验证计划面板、训练方式弹窗、回顾切换、键盘焦点和切换时的页面高度/滚动位置。自动化工具定位按钮可能自行滚动，最终滚动稳定性以同排按钮的键盘切换验证。
- 390 像素走通首页方式选择、按今日计划启动、完成一组、反馈、返回首页续练状态；未保存草稿不计入今日汇总。
- 未重建 APK、未进行安卓真机验证。
