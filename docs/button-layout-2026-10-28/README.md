# 手机按钮布局走查与修复（2026-10-28）

网页开发服务已在 `http://127.0.0.1:4173` 启动。使用隔离 Chrome 浏览器走查与 Android WebView 共用的页面资源，没有读取真实用户资料或写入用户记录。当前环境没有可用的 adb 或 Android 模拟器，未在安卓真机启动应用，未验证系统软键盘、系统字体缩放或原生更新页。

## 发现与修复

| 范围 | 原问题 | 修复 |
| --- | --- | --- |
| 训练、饮食及身体弹窗顶部 | 返回按钮 36 / 44 像素，关闭按钮 40 像素；标题与返回按剩余空间散开 | 返回和关闭统一为 44 像素；标题占剩余空间，返回与关闭靠右并垂直居中，关闭不被挤压 |
| 主次操作按钮 | 常规 44 像素与重点操作 48 像素混用；确认放弃仅 36 像素 | 主次操作至少 48 像素；相同确认操作区统一高度、宽度、行高及内边距 |
| 训练商城底部 | 按文案宽度和 space-between 分布，按钮宽窄不一 | 两项操作等宽；三项操作在不超过 430 像素时逐行铺满，宽屏等分；保留清单数量区布局 |
| 模板编辑及设置 | 同组修改与移除尺寸不同，设置入口随文案决定宽度 | 操作区用等宽网格，设置入口整行显示并留出说明间距 |
| 饮食确认、份量及选餐底部 | 多套按钮和份量宽度规则叠加 | 确认操作等宽等高；份量四列等分；底部主次操作统一高度，添加按钮统一最小宽度与对齐 |
| 训练准备卡片 | 行内文字长度变化时视觉高度不齐 | 网格行等高，卡片填满网格高度，保留现有四项分步入口 |

仅修改 `styles.css`、`home.css` 和 `nutrition.css`。没有增加折叠抽屉或修改业务、持久化与导航逻辑；暂停圆形控制、列表卡片、日期选择等保留各自用途与样式。
