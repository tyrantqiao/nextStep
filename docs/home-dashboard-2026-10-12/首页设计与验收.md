# NextStep 0.7.1 首页设计与验收

日期：2026-10-12。依据用户提出的数据仪表盘、右下角开练入口、今日已练按钮调整与整体动线优化。此次在 0.7.0 改动基础上完成，没有覆盖其他未提交文件或清空数据。

## 首页结构

1. **今日数据**：主卡突出已保存训练的整次分钟，配保存次数和完成力量组；辅卡显示已有今日步数、可用运动估算消耗。没有数据时，训练显示真实 0，步数/消耗显示 —，不把未知值当零。
2. **计划状态**：今日待练、计划休息、计划已完成或未设置，用紧凑摘要展示；动作及偏好继续在并列的本周计划页查看。
3. **本周节奏**：完成环对应用户已经设置的每周力量计划天数，七天时长图对应真实整次分钟；点击日期直达当天记录，未来日期禁用。首页图表不受记录页周/月选择影响。
4. **今日记录**：保留实际活动类型、泳姿、用时与距离等摘要，主体进入详情并可纠错；超三条提供查看全部。

不新增健康评分、恢复建议或假目标。运动估算消耗沿用已有热量，说明含静息、不含力量训练；混合记录的分项分钟不再次加到整次分钟。未保存草稿不计入仪表盘，单独状态条提示去继续或完成保存。

## 入口与动线

| 状态 | 固定入口 | 点击后 |
| --- | --- | --- |
| 今日没有保存训练、无草稿 | ＋ 开练 | 选择按今日计划、自由计时或补记运动；打开选择页不开始计时 |
| 今日已经保存训练、无草稿 | ＋ 再练一次 | 明确新记录单独保存；今日计划已完成时使用再按今日计划练文案 |
| 训练进行中 | 继续训练 | 直接回到当前训练，不创建新草稿 |
| 训练暂停 | 继续训练 | 回到暂停画面，保留继续与结束操作 |
| 已结束但尚未保存 | 完成保存 | 直接回到结束反馈，保留原结束时间 |

未建计划或计划休息日不强制设置，仍可自由计时/补记。今日按计划入口依据真实当天，不受预览其他日期影响。补记返回保持首页开练选择；关闭恢复固定入口焦点。跨页返回首页默认仪表盘，计划所选日不被清除。

固定入口在手机位于底部导航上方，计入安全区；页面末尾保留操作留白。移除仪表盘父容器的进入位移动画，避免 transform 暂时改变 fixed 定位，导致按钮首次出现偏离视口。周计划页不额外叠加浮动按钮，沿用所选模板训练入口。
