# NextStep 0.8.5 · 饮食店铺与快捷整餐

## 更新内容

- 选餐先进入店铺Tab，选择麦当劳、肯德基等店铺后查看独立菜单，跨店加购、店内搜索和刷新续填保留选择。
- 增加同昨天、同最近一次和常吃整餐一键记录，保留食品份量及热量方式。
- 购物车内直接选择半份、一份、一份半、两份或实际用量；确认页只显示摘要，需要修改时再编辑。
- 135项内置食品均有热量参考，补齐17项缺失值。官方数据、配方估算和港/台参考分别标明，历史食品快照保持。
- 今日与计划并列切换，直接编辑单日训练安排；设为每周重复采用独立确认，保留其他日期和训练草稿。
