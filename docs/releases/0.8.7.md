# NextStep 0.8.7 · 支撑动作、逐组记录与按钮布局修复

## 更新内容

- 新增「平板支撑」「平衡板」，默认每组目标 30 秒，训练时分别填写实际秒数。支持搜索、动作示意、加入计划、训练中添加与替换。
- 俯卧撑等自重动作明确区分目标和实际次数，每组可以多做或少做，例如分别记录 12、8、15 次。
- 完成本组直接读取当前输入，实际数值与完成状态一起保存；保存失败后保留表单和草稿，支持重试、刷新续练、上一组纠正和历史编辑。
- 统一手机界面的弹窗返回与关闭按钮、主次操作高度及同组等宽布局；修正训练准备卡片、训练商城底部、模板编辑、饮食份量与确认区的对齐。
- 窄屏三按钮确认区改为逐行排列，避免文案宽度造成按钮大小不一。保留原有分步选择流程，不增加折叠抽屉。
- 保留旧资料、记录及草稿。未标注单位的旧逐组数据仍按次数显示，自重与按秒动作不计入负重吨位，训练总用时继续按实际开始和结束时间计算。
