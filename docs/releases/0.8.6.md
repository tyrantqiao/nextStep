# NextStep 0.8.6 · 全天消耗、饮食关联训练与更多店铺

## 更新内容

- 饮食摄入下增加全天预估消耗，分列日常基线与已保存训练的额外消耗；饮食记全且热量完整后展示差额。
- 个人资料可选填写估算年龄、公式性别与日常活动水平，独立查看公式、数据来源和适用范围。历史日期按当前资料重算，原手填饮食目标、维持消耗及快照保留。
- 今日和训练记录页结合饮食完整度、摄入、原计划与已完成训练提供今日方案。确认后才开练，不因漏记减量或高摄入追加抵消训练，不重写原计划和草稿。
- 新增56项食物，食品目录共191项；新增必胜客7项、海底捞13项独立参考菜单，支持搜索、跨店加购、份量调整与刷新续填。
- 披萨注明参考片或100g口径；火锅食材、汤汁、附着油和蘸料分别记录。新增食品均标明基础数据或独立配方估算，旧记录来源快照保持。
