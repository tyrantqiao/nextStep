## NextStep 0.8.4 · 训练计划与动作选择统一

- 今日始终提供开练、继续训练或完成保存入口，与记录页共用训练准备页。
- 新增今天与本周动作清单：按部位、器械、关键词筛选，连续选动作后集中设置组数、次数、参考重量及顺序；支持只保存指定日期。
- 商城、训练中添加和替换动作使用一致的列表、最近练过、筛选、示意预览与自定义动作入口。重选同一动作保留已填参数。
- 训练中、休息中和暂停时都能直接结束；摘要列出未完成组，保存仅统计已完成项目。替换动作保留已完成组，保存失败可重试。
- 跨日或长时间未结束的草稿先提示核对，可填写实际结束时间；计划状态改为“已按计划训练”，避免将部分训练称作全部完成。

下载 `NextStep-0.8.4.apk` 覆盖安装，请勿卸载旧版。需要 Android 8.0 及以上；饮食与身体保存需要支持 Web Locks 的新版系统 WebView。沿用包名 `com.nextstep.training`、本地来源与原签名，保留已有资料、记录和草稿。

附件：APK、SHA256校验文件、应用内更新清单 `update.json`、合集 ZIP。

验证：215项Node回归、25项JVM更新策略检查；真实浏览器320/390/1280像素的训练与动作选择验收；APK结构、资源与DEX对齐、v2/v3签名及网页资源一致性校验。未进行安卓真机、软键盘或覆盖升级测试。

验收说明：[训练链路](https://github.com/tyrantqiao/nextStep/blob/v0.8.4/docs/training-flow-2026-10-20/README.md)、[动作选择](https://github.com/tyrantqiao/nextStep/blob/v0.8.4/docs/exercise-picker-2026-10-20/README.md)。
