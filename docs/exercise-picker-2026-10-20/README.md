# 动作选择统一与验收

## 已实现

商城批量选择、训练中添加、替换当前动作共用 `exerciseBrowser` / `exerciseResults`，统一为：

- 「全部动作 / 最近练过」并列切换，搜索、器械与部位取交集；三个入口都直接显示筛选，不再经过公仔与器械独立步骤。
- 相同的动作卡片、元数据、最近练过标记及可点击动作示意。预览可暂停动画、返回原列表，或直接执行当前任务。
- 商城支持连续加入/移除，底部显示已选数量，再集中填写参数。添加为单选，选择后填写参数；替换为单选，只作用于未完成组。
- 三处均有自定义动作入口，沿用 `profile.customExercises`。商城可保存并加入清单，替换可保存并替换未完成组；无内置动画的自定义动作如实标注。
- 单项重选保留搜索、部位和器械；重选相同动作不覆盖已填组数、次数和实际重量。
- 选择列表独立滚动，筛选和底部操作可见；没有新增折叠抽屉。

沿用原商城草稿、日期安排及存储结构。商城加购写入失败恢复原清单；替换写入失败保留原训练和当前动作索引。现有运动项目选择与运动参数流程继续保留。

## 真实浏览器验证

使用临时测试入口及该标签页专用的 sessionStorage 适配 localStorage，加载实际网页脚本与样式，未向真实用户存储写入测试训练、计划或自定义动作；测试入口交付前删除。

1. 新安装空白页→自选动作；最近练过为空，不注入示例数据。
2. 商城选择手臂＋徒手＋“俯卧撑”，得到6个复合动作匹配；动作示意暂停、预览加入、返回筛选正常。
3. 俯卧撑设置2组×12次，返回后搜索仍为“俯卧撑”；新建“测试弹力带推举”并加入同一清单，原参数保持。
4. 保存并开练，完成1组；训练中添加使用同一筛选界面。最近练过显示当前真实完成的俯卧撑。
5. 添加哑铃划船，填写4组、13次、17.5kg；重选同一动作后三项参数保持，添加并刷新后仍可继续训练。
6. 完成哑铃划船第1组，从工具进入替换；相同筛选得到6项。预览返回与自定义页返回均保留筛选；从预览将剩余3组替换为俯卧撑。
7. 结束并保存，记录保留俯卧撑12次和哑铃划船17.5kg×13次，合计2组、227.5kg吨位；未完成组不计入。
8. 商城、添加、替换分别在320×740、390×844、1280×900检查：整页与弹窗均无横向溢出，筛选和底部操作在视口内，单项选择页不需要整窗纵向滚动才能找到底部操作。测量见 [browser-results.json](browser-results.json)。
