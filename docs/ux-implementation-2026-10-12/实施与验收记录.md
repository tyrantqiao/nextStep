# NextStep 0.7.0 优化实施与验收记录

日期：2026-10-12。依据：[体验走查与优化报告](../ux-review-2026-10-11/优化报告.md)。报告三批实施范围及 14 项问题均已落实。报告明确另立需求的泳池长度、趟数、配速、备注、计划改期及自动训练建议不在本次范围。

## 改动对照

| 问题 | 实施结果 |
| --- | --- |
| 01 今日活动不可见 | 当天已保存活动及指标直接展示，最多三条，更多直达当天记录。历史补记不混入今日。 |
| 02 完整训练身份丢失 | 按实际运动与已完成力量组生成图标、文字类型和项目摘要，适配纯运动、力量、徒手与混合记录。 |
| 03 类型修改名称不同步 | 真实名称按代码识别，默认标题随类型更新，自定义标题保留；代码、MET、热量与动画同步。未知旧代码安全回退。 |
| 04 补记与计时混淆 | 开始计时与补记已完成运动分别命名；结束反馈解释整次与分项用时，明显矛盾提供纠正入口及继续训练。 |
| 05 距离不能纠正 | 单独及混合运动支持距离编辑、清空与有效值校验，相关展示同步刷新。 |
| 06 成功反馈无摘要 | 持久显示本次活动摘要，提供回到今日与查看本次记录；只有保存成功后才推进。 |
| 07 周计划抽屉 | 今日/本周计划并列切换，偏好集中在调整计划独立步骤，选中日期保留。 |
| 08 计划缺执行状态 | 明确实际日期、休息、待练、未记录、已完成与额外运动，侧栏改为本周力量计划。运动不误计力量计划完成。 |
| 09 首页入口落到统计 | 查看今日记录直达当天筛选，统计趋势独立进入。 |
| 10 指标偏力量 | 纯运动不突出零组数/零吨位，徒手按实际动作/组数展示；统计增加运动组成。整次与分项分钟不混加。 |
| 11 编辑返回不连贯 | 列表主体可点击，详情直接编辑/删除；取消回原详情，关闭恢复可见入口焦点和位置，删除二次确认。 |
| 12 训练空状态过时 | 已添加运动显示项目数量与适配图标，纯运动隐藏空组进度，暂停、续练和结束待保存显示正确状态。 |
| 13 参数页重复选择 | 项目选择与参数分步，泳姿/强度限同类别；重选保留输入，估算依据独立查看，最近使用称最近练过。 |
| 14 历史定位困难 | 类型筛选、名称搜索、日期分组、结果空状态与分页；日历点击日期显示具体活动和详情入口。 |

## 数据与交互规则

- 保留原有 localStorage 键和数据，未清空或注入用户资料。已完成力量组才计力量摘要与计划完成，同一本地日期计一次。
- 整次时长依实际开始与结束计算，含休息、暂停及离开时间；反馈用时不计入，分项分钟不额外累加。
- 编辑未改变整次分钟时保留原始秒数与起止时间；草稿分项纠错保留冻结结束时间和休息状态。
- 保存失败保留输入/草稿供重试；校验有限值、范围、整数，提供中文错误信息。动态文本继续转义。
- 热量沿用既有 MET 与公式，标注含静息消耗、非实测，依据可查；本次未新增 MET。
- 关键重设计使用并列切换或独立步骤；原有健康同步、设置及重量参考等辅助区域的历史折叠不在主页面重设计范围。
