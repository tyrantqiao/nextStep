# 一日饮食时间线验收

四个餐次沿时间线排列，顺序为早餐、午餐、晚餐、加餐，均可直接添加。同餐多条记录分别展示；单条记录的热量集中在餐次小计，食品行展示名称与实际份量。

已执行 JavaScript 语法检查和185项 Node 回归测试。新增断言覆盖餐次顺序、空记录不写入存储、同餐多条汇总、食品份量、未知热量与真实零热量、整餐手填覆盖、未吃与未记录区别，以及动态文本转义。

真实浏览器在独立来源 `http://127.0.0.1:43396` 验收，没有写入日常使用来源的饮食数据：

- 390×844：空白日四餐入口、早餐添加蛋糕50g、午餐添加米饭与待填热量的汉堡；食品选择、份量填写和保存。
- 320×740：长食品名和待填提示无横向溢出；从时间线打开详情、编辑早餐为60g，早餐约191kcal，全天已知约386kcal；未吃切换后焦点保留在原入口。
- 切换到前一天显示空时间线，返回今天保留记录；确认记全后仍明确显示待填热量，不据此计算有效缺口。
- 1280×900：检查时间线布局、每日汇总和下方两列信息，无横向溢出。
