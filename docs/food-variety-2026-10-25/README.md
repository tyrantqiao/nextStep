## 热量与份量

22项基础食物来自实际下载的 [USDA SR28 ABBREV.txt](https://www.ars.usda.gov/ARSUserFiles/80400535/DATA/SR/SR28/dnload/sr28abbr.zip)，按每100g可食部记录，明确生重、熟重、干重、去核或去骨口径。选定行保存在 [usda-selected-references.json](usda-selected-references.json)，下载包SHA256保存在 [added-foods-audit.json](added-foods-audit.json)。仅保留所需数据，不打包完整原始压缩包。SR28为历史参考数据，不是当前中国品牌包装或门店的实测。

25项新配方沿用基础食物逐项合计，保留原料、数量、单位和热量依据。剩余9项海底捞食材复制对应通用食材的每100g参考，注明不是门店每份规格。56项完整条目、热量及配方见 [added-foods-audit.json](added-foods-audit.json)。食品版本更新为 `2026-10-25.1`，旧记录、收藏与草稿的已有热量快照不重写。

必胜客官网和海底捞官网用于品牌、餐饮类别和菜名背景：

- [必胜客中国菜单](https://www.pizzahut.com.cn/Product)、[百胜中国品牌介绍](https://ir.yumchina.com/zh-hans/our-brands/)：不作为本应用参考配方的热量来源，也不保证条目在当前门店供应。
- [海底捞特色菜](https://www.haidilao.com/cate/dish/specialty)：用于捞派虾滑等菜名背景。虾滑采用应用自己的明确食材假设，不声称复现品牌虾肉比例或生产工艺。

披萨分别说明“自定参考片”或“通用芝士披萨100g”，不把不同尺寸、饼底或切片数视为同一热量。烤翅按带皮熟可食部计算，不把含骨重量当肉重。火锅按个人吃进的食材量记录，汤汁、附着油和蘸料独立选择，不把整锅作为一人摄入，也不因不喝汤就假设附着油为零。以上均非门店官方营养值，可按实际食用量或标签编辑。
