# 最近一餐与常吃整餐快捷入口

本轮仅更新网页，未重建APK。

- 最近一次按所查看日期之前的设备本地日期查找，仅复制对应餐次；与「同昨天」互斥展示。复制最近一天该餐次的全部记录，保留每条记录的热量方式及食品依据。
- 空餐次提供常吃整餐列表。收藏入口在餐食详情和保存前的确认页，命名后保留份量、餐次、备注及整餐手填热量；收藏本身不计入摄入。
- 新收藏按餐次显示，旧版未标餐次组合在各餐次均可使用。沿用 `nextstep.nutrition.favoriteCombos`，新增元信息为可选字段，无须迁移或清空旧数据。
- 快捷保存与普通保存使用相同的份量精度和单餐热量上限；不覆盖已有餐次或草稿。整餐手填热量不叠加食品分项。失败不推进状态，可原地重试。

## 验证

`node --check nextstep-web/dist/nutrition.js`、`node --check nextstep-web/dist/app.js` 与229项Node回归通过。

`node docs/nutrition-shortcuts-2026-10-24/verify.cjs` 使用隔离临时浏览器资料和随机端口的本地静态服务器，运行真实无头Edge；不会访问日常使用来源的数据。14项浏览器检查结果见 [results.json](results.json)。脚本使用默认Edge路径和调试端口9346，可按本机环境调整。

已检查320、390、1280像素宽度的时间线和常吃列表，无整页或弹窗横向溢出。已验证整餐收藏表单、最近一次多条记录复制、手填热量、失败重试、刷新恢复与旧收藏筛选。未进行安卓真机或软键盘测试。
