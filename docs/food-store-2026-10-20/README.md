# 店铺式图文食品菜单验收

菜单采用固定搜索、左侧分类、右侧图文食品列表和固定底部已选入口；分类与食品列表分别滚动。常吃和搜索并列，按店铺可继续筛选具体店铺。添加食品后继续选择，已选清单可查看和移除，最终仍在独立份量页保存。

设计参考：[美团新商家手册的菜单组织说明](https://s3plus.meituan.net/v1/mss_1161d28e78554b4390e03672b19f818f/waimai-cd-fe-agent/%E6%96%B0%E5%95%86%E5%AE%B6%E6%89%8B%E5%86%8C.pdf)。未复制商家的菜品照片、品牌宣传或交易流程。

## 样图

使用imagegen生成三张本地图集，共88个通用食物样图单元。135项内置食品全部匹配样图，同类食品复用；品牌食品只是通用类别示意，不是实物照片，不参与份量和热量计算。界面统一显示AI样图说明。自定义食品未匹配时显示待配图。

## 验证

191项Node回归通过，覆盖原训练/饮食/资料/时间线、分类与搜索、图片索引范围、常吃连续选择、已选移除、保存失败的本地可重试状态、份量与草稿保留、Android三张图片逐字节复制及导出适配。

真实应用内浏览器采用独立来源 `http://127.0.0.1:43590` 的测试数据，未修改日常使用来源的饮食：

- 320×740：水果、蛋糕及店铺筛选；无整页和弹窗横向溢出，外层无需滚动寻找操作；底部可见。
- 390×844：早餐样图、按分类和关键词筛选、连续添加西瓜和蛋糕、查看已选、移除、返回保留关键词；50g蛋糕刷新续填后保存约160kcal。
- 常吃食品加入后保留菜单，可继续选择。
- 1280×900：无横向溢出、无弹窗外层滚动，独立分类/列表与固定底部操作正常。
