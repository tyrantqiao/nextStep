# NextStep 0.7.2 简洁首页验收

日期：2026-10-12。依据用户提出的首页简化、增加饼图/柱状图与丰富数据类型。

## 设计结果

移除大蓝色主卡、独立计划说明区、鼓励性长文案与重复数据。首页保留四项摘要、一对图表及短记录列表；今日/本周计划并列切换和右下角状态化开练继续保留。

| 区域 | 展示与规则 |
| --- | --- |
| 今日摘要 | 已保存整次分钟、记录次数、已有运动估算消耗、已有今日步数；消耗不含力量且含静息，未知值用 — |
| 计划状态 | 一行今日计划状态及本周完成天数，不再展示独立计划卡或长解释 |
| 柱状图 | 时长、次数、吨位、步数、距离五项并列切换，周一开始计周；图表局部更新，保留焦点和滚动 |
| 环形图 | 本周实际项目次数，区分力量/游泳/跑步/步行徒步/爬楼/水上/其他；混合记录分项计数，不将力量时长凭空从整次用时中拆出 |
| 辅助数据 | 完成组、已完成负重吨位、已填距离按有值展示在构成图底部 |
| 今日记录 | 最多两条短摘要；更多记录进入当天列表，保留类型图标、实际泳姿/指标、详情与编辑入口 |

距离明确是已填合计，步数是已保存合计；不同时间范围不混淆。运动分项分钟不重复加到整次时长，热量沿用既有 MET 未新增数据来源。空构成图使用灰色中性环，没有假分类或演示数据。

## 验证结果

自动检查：JavaScript 语法、122 项业务测试、4 项 Android 工具测试、25 项 JVM 更新策略检查和 git diff --check 通过。新增回归覆盖混合项目计数、力量未完成不计入构成、距离汇总、历史日期排除、未知值/真实零、图表选择与焦点、独立统计范围、空环及旧活动安全回退。

真实浏览器使用独立测试来源 4188（前次走查的虚构游泳及力量记录）和 4189（空数据新来源），没有访问用户真机数据。检查 320×568、390×844、1280×720 下的有记录首页与图表，另查 320/390 空首页、320 开练选择和短记录详情返回。

页面宽度 305/375/1265 未超出各视口；趋势自身 scrollWidth 与 clientWidth 相等（242/306/468），开练弹窗 320 像素下自身宽度与滚动宽度均为 252。手机固定按钮稳定位于底部导航上方。390 像素四次趋势切换滚动均保持 0 → 0，焦点保持所选按钮；320 像素详情关闭恢复记录入口。控制台未发现错误。
