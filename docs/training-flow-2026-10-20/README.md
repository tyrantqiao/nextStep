# 今日与训练统一方案

## 页面职责

| 页面 | 内容与主操作 | 返回规则 |
| --- | --- | --- |
| 今日 | 今天安排、常驻开练/继续/完成保存、已保存活动、饮食身体摘要、今日记录、本周回顾 | 主导航切换不影响训练草稿 |
| 训练准备 | 按今日计划、自选动作、立即计时、补记已完成运动；各入口明确何时计时 | 今日和记录页共用；从计划进入可返回计划 |
| 日期计划 | 选择一天、查看动作、编辑这一天；单独入口管理整周及周期模板 | 选中日期不影响“今日计划”；文案使用具体日期 |
| 动作清单 | 搜索/部位/器械/最近练过，多选后集中填参数、排序、预览 | 三步：选动作→设参数→确认；返回保留清单，关闭后可续填 |
| 正在训练 | 当前动作、重量次数、完成组、休息、可选感受、暂停、结束、工具 | 工具返回训练；离开窗口保留草稿且总时长继续累计 |
| 结束摘要 | 已完成/未完成组、起止时间和整次用时、可选整体感受、检查修改、保存 | 提前结束可返回继续；保存失败保持可重试 |
| 记录 | 历史搜索筛选、详情编辑、完整统计、每日活动 | 保存成功可回今日或查看本次；旧 #trends 保持兼容 |

## 统一链路

1. 今日与记录的开练按钮进入同一准备页；有草稿时进入原训练，不另开一份。
2. 按今日计划只读取设备本地今天的有效安排，不自动换成未来计划。
3. 自选动作在选择、填参数和预览时不计时；确认开练后才开始。立即计时允许边练边添加，界面明确包含准备时间。
4. 计划与自由训练均可直接点击结束，进入同一摘要；未完成组明确列出并不计入保存结果。完成最后一组仍可快捷进入摘要。
5. 保存成功后统一回到今日或查看详情；只有保存记录计入今日与统计。
6. 关闭窗口不等于暂停。跨日或超过六小时的草稿显示开始时间、归属日期和核对用时入口；用户明确修改结束时间，系统不自动截断。

## 日期和状态规则

- 今天、指定日期单日、当前整周是三个明确范围。编辑单日只写该日期；整周保存明确写入七天（含休息日）。
- 日期安排优先于周期模板。生成模板不会覆盖已指定的日期，设置页明确说明。
- “已训练”表示当天有已保存记录；“已按计划训练”表示当天有有效计划力量记录，并不等于全部动作完成。沿用已有记录结构，不虚构旧记录的完整完成度。
- 草稿状态：进行中→暂停/继续→结束待保存→已保存；关闭、刷新、存储失败不会清空草稿。
- 整次时长包含休息、暂停和关闭窗口期间，结束摘要与反馈时间不计入；归属开始日期。补记运动使用实际输入日期和用时。

## 验证结果

已完成本轮核心范围。JavaScript 语法检查通过；训练与饮食合计 203 项 Node 回归通过（训练 158、饮食 45），新增 9 项覆盖统一准备、日期隔离、单日保存失败、步骤返回、提前结束、旧草稿提示、时间纠正失败重试、部分计划文案和毫秒精度。

真实浏览器验收：

- 320×740、390×844、1280×900 检查首页、训练准备、商城与结束摘要；整页和相关弹窗无横向溢出，商城底部操作在视口内。较长的结束摘要允许纵向滚动。
- 空白状态仍有开练入口，打开准备页不启动训练；记录页开练使用相同选项与今日安排。
- 自选俯卧撑→3组×12次→保存并开练→完成1组→反馈→休息→直接结束；摘要明确还有2组未完成。
- 刷新恢复待保存草稿→核对结束时间→保存→今日更新1次/1组；保存后仍有“再练一次”。
- 单独安排周三的哑铃划船，7.5kg参数在返回选择后保留；保存只写周三，周二原有俯卧撑安排保持。周三不提供“保存并开练”。
- 自由立即计时→添加步行→直接结束→相同摘要→保存成功；整次用时与运动分项分别展示。
- 实际旧草稿显示原始开始日期和核对时间提示，只查看与关闭，未修改其训练内容。
- 时间表单在320像素不横向溢出；无效结束时间、早于已完成组、晚于现在、存储失败和原时间戳精度由Node回归覆盖。

浏览器完整流程使用临时测试页面，将 localStorage 替换为该标签页独立的 sessionStorage 适配器；网页业务、样式和用户点击流程使用实际源码。测试页面交付前删除，未向真实用户存储写入测试训练和计划。布局测量见 [browser-results.json](browser-results.json)。
