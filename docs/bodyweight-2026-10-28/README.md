# 平板支撑、平衡板与逐组实际输入（网页，2026-10-28）

动作库新增平板支撑（核心 / 徒手）和平衡板（核心 / 平衡板器械），可搜索、查看本地 SVG 示意、加入日期计划和在训练中添加或替换。两项默认 3 组、每组目标 30 秒，实际每组可独立填写 1–3600 的整数秒数。示意不是完整技术教学。

俯卧撑等次数动作的准备页将次数明确为目标，训练页填写「实际次数」，每组可多于或少于目标。完成按钮直接读取当前输入，与完成状态一起成功保存后再推进；输入事件写入失败不修改内存草稿，保留表单供重试。仍支持休息、逐组感受、上一组纠正、撤销、刷新续练和历史编辑。

保留 localStorage 键、`type: 'bodyweight'`、`weight: null` 和既有数值 `reps` 字段。新增 `measure: 'seconds'` 表示该字段的单位为秒，`measure: 'reps'` 表示次数；历史明细、编辑、计划和导出使用同一单位。没有单位标记的旧逐组记录与草稿继续按次数显示。自重及按秒记录不计入负重吨位，整次训练用时仍按开始和结束时间计算，不把手填秒数追加到整次时长。

验证：JavaScript 语法检查，255 项训练 / 饮食 Node 回归通过；隔离 Chrome 浏览器 81 项检查通过，覆盖 320 / 390 / 1280 像素的选择、表单、逐组提交、刷新恢复、上一组与历史编辑、购物车参数、统计切换焦点、横向溢出和保存失败重试。浏览器检查脚本与结果保存在本目录，可执行 `node docs/bodyweight-2026-10-28/browser-check.cjs`；使用隔离临时浏览器资料和独立端口，不读取用户浏览器数据。
