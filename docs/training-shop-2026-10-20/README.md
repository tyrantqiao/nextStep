# 训练动作商城与日期安排

入口：首页「本周计划 · 选动作」→「挑选今天动作 / 定制本周安排」。准备开练页也可选择「挑选动作再开练」。无需先填写个人资料或生成规则模板。

- 左侧按部位分类，右侧动作示意卡片；搜索、器械与部位共同筛选，「全部动作 / 最近练过」并列切换。
- 点击＋连续添加，已选显示勾选；底部固定显示当天动作数、组数和清单入口，列表独立滚动。
- 购物车统一填写组数、次数和参考重量，支持移除及上下调整顺序；自重训练不填写重量，哑铃按单只记录。
- 今天与本周七天可分别配置，空清单表示休息；预览日期与参数后保存，保存本身不计时。今天可「保存并开练」，已有训练时继续原草稿。
- 具体日期安排保存在原 profile 的 scheduledWorkouts，优先于周期模板；今天修改只影响当天，本周保存只影响当前周，未来仍沿用原周期模板。首页七天、今日状态和本周目标同步读取有效安排。
- 购物车沿用 profile 存储，关闭与刷新可续填；今天保存后保留其他日期的未保存选择。跨周草稿不误套到新日期，旧模板、历史记录与正在训练的草稿保持。
- 保存失败保留清单并允许重试；导出 profile 时包含日期计划与已持久化的选购草稿。此版本没有发布新 APK。
