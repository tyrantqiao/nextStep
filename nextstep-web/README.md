## 动作热量公式、冲浪动作与逐组反馈（网页）

所有内置运动和力量/次数动作在参数页或训练页显示 `估算 kcal = MET × 体重 kg × 实际运动分钟 ÷ 60`，注明含静息消耗、非实测。原运动沿用现有 MET；负重动作按 2024 Adult Compendium 的一般负重训练 3.5 MET（02054），次数动作按一般自重训练 3.0 MET（02056）作类别参考，不声称是动作专属测量值。来源：[Conditioning Exercise](https://pacompendium.com/conditioning-exercise/)。

训练结束后可点击「填写动作用时，估算热量」，录入各动作排除休息、暂停和其他运动后的实际分钟数以及记录时体重。未填用时不估算，也不根据次数或吨位推算。各动作合计不能超过整次训练用时；分项不增加整次时长。估算以可选 `items[].calorieEstimate` 保存，包含 MET、活动代码、体重、用时、公式和来源；首页、历史摘要、运动组成、详情与 JSON 导出包含已估算项目。历史编辑可补填或纠正估算的用时和记录时体重。旧数据不自动补算、不清空。

动作库新增「冲浪起乘」（徒手次数、核心）和「冲浪哑铃划水」（哑铃负重、背部），均可搜索、加入训练或模板、查看循环示意；哑铃按单只重量记录，1 kg 仅为试练参考。

每组成功记录后进入独立感受页，提供轻松/合适/吃力或暂不反馈。待反馈状态随草稿保存，刷新续练仍询问；写入失败保留可重试状态，重复完成不推进。休息从完成组时开始，选择感受不重置倒计时；自动结束的最后一组在完成时冻结时间，反馈用时不计入。每组感受与整次感受分别保存。

验证：JavaScript 语法检查与 131 项业务回归测试通过。真实应用内 Chromium 浏览器走通动作搜索、组完成、刷新续练、逐组反馈、休息、结束、估算、保存、详情与编辑返回；检查 320/390/1280 像素布局及运动强度切换后的公式和热量，无整页/弹窗横向溢出。已重新构建并校验 Android 0.7.4（versionCode=29），发布资产见 [v0.7.4 Release](https://github.com/tyrantqiao/nextStep/releases/tag/v0.7.4)。未进行安卓真机验证。
