## 0.5.1 Android 健康步数记录

今日概览新增每日活动卡，Android 14+ 安装包通过 Health Connect 授权读取今日与最近七天每日步数。显示无数据、权限及服务错误状态，支持手动刷新。网页浏览器显示 Android 安装包接入提示。每日步数保存到独立的 nextstep.activityRecords，本地长期保留，按日期更新累计值；记录页可查看所有已保存日。JSON 导出 version=2 包含 activityRecords，保留原有 profile、records。无数据不覆盖历史，保存失败支持重试。步数不计入训练次数，不推算时长和热量。详情和 Find X8 Ultra / ColorOS 16 测试步骤见 `../android-app/README.md`。

启动：`node serve.cjs`，访问 `http://127.0.0.1:4173`。

训练记录与统计趋势已合并到「记录」页面。支持逐组力量训练记录、草稿续练、按本周或本月统计训练次数/时长/完成组数/训练吨位、每日时长图、全部历史和逐组详情、JSON 导出。周一开始计周，按设备本地日期统计；训练吨位为已完成组的重量 × 次数之和，哑铃使用输入重量，不自动乘二。

数据保存于本机 localStorage，兼容原有记录。保存失败保留训练草稿供重试。旧 `#trends` 链接仍可打开合并页面。

首页训练次数和时长读取真实记录；恢复、饮食、训练计划与加重建议仍是演示内容。账户、后端同步、有氧录入和个性化算法尚未接入。安卓壳共享这套网页资源，网页更新后需重新构建 APK。

验证：`node --test tests/journal.test.cjs`。

## v0.3 计划与设置

主导航为今日概览、记录、训练计划。资料和训练偏好通过顶部、侧栏或计划页的设置按钮打开。首次使用（包括尚未完善新字段的旧资料）提醒设置；距上次使用至少 30 天时提醒确认当前状态。可以稍后处理；正在训练时以页面提示保留草稿，避免自动弹窗打断。

保存称呼、身高、体重、生活方式、目标、训练经验、器械、每周频率与单次时间后，生成每周力量训练模板。频率决定训练日，器械决定动作，目标决定初始次数，经验/时间/体力负荷决定动作数量与组数。训练重量由用户填写，不根据身高体重推算。保存资料与计划采用同一次本地写入；已有训练草稿和记录继续保留。

这是本地规则模板，尚未接入根据训练表现动态调整计划的算法。网页已更新，安卓 APK 需重新构建后才能使用新流程。

## 0.4.0 动作与运动记录

训练界面无更多操作，动作标题旁可替换未完成组，已完成组保留。计时区按住结束 1.2 秒后进入反馈页，释放提前取消，键盘按住空格/Enter 同样适用。

动作库包含 35 个动作与徒手、哑铃、杠铃、固定器械、绳索、壶铃、弹力带分类。计划重量优先沿用最近同名动作的已完成实际重量；无历史时提供轻负重试练参考，需按实际器械和能力确认，并非个人能力计算结果。哑铃按单只记录，杠铃应包含杆重，器械重量按实际标示填写。负重组在完成和最终保存时校验大于 0 kg；次数训练使用 type=bodyweight、weight=null，不计算外部负重吨位。旧历史不删除。

其他运动支持 15 种活动/强度：爬楼、游泳、冲浪、桨板、皮划艇、步行、徒步、慢跑。录入运动时长、体重和日期，预览并保存估算总消耗；按 MET × kg × 小时计算，含静息消耗，非实测。来源为 2024 Adult Compendium（19–59 岁）：https://pacompendium.com/ ，具体活动值来自 walking / water-activities / running 页面。每条运动记录保存 MET、活动代码、体重和公式，计入时长图与日历。力量训练尚未估算热量。

27 项自动检查通过，手机运动录入与热量预览检查通过；未真机验证。APK 仍不预设用户资料或测试记录。

## 交互优化（网页）

计划完成率仅统计 mode=plan 的已保存训练，同一本地日期计一次；自由训练和其他运动仍计入训练次数、时长等活动统计。旧记录保留，未标记为计划训练的历史不推断为计划完成。其他运动不会推动首页跳到下一次力量训练。

训练方式选择和自由训练准备中可设置 60/90/120/180 秒组间休息；训练中通过「训练设置与纠错」调整后续休息，不改变当前倒计时。开始前选择保存在现有资料中，训练中调整随草稿保存。

「训练设置与纠错」支持修改最后完成组的重量和次数，或撤销完成重新记录。修改保留完成时间和当前休息，撤销清除休息并返回该组。可确认放弃本次草稿；删除失败保留草稿以便重试，已有记录不受影响。关闭窗口仍持续计时。

验证：34 项业务回归测试及 JavaScript 语法检查通过；浏览器检查了独立测试来源的组完成、修改、撤销、休息设置，以及 320/390/1280 像素页面布局。未重新构建 APK，未进行安卓真机验证。

今日概览进一步精简为训练入口与四个紧凑指标，移除重复的训练图表、日历和最近记录；这些内容仍可在记录页查看。首页隐藏页脚，其他页面保持原有布局。浏览器检查 320×568、390×844、1280×720 视口，首页页面尺寸未超出视口，内容未被移动导航遮挡。34 项业务回归测试与语法检查通过；此次仅更新网页，APK 未重新构建。

## 一次完整训练（网页）

开始训练 →「开始一次训练」会立即开始整次训练计时。可以陆续添加负重动作、俯卧撑等次数动作，以及跑步、游泳等运动；运动记录填写实际运动时长、体重和可选距离（米）。完成所有力量组后仍保持计时，长按结束后统一保存为一条记录，首页、周/月统计和日历只计一次训练。

总时长按本次开始到结束计算，包含休息和关闭窗口期间；各项运动的时长不再额外累加到总时长。力量只统计已完成的组与外部负重吨位，哑铃按单只重量记录。运动热量仍使用现有 MET 数据估算，含静息消耗，各项运动分别保留估算依据。反馈用时不计入训练时长。

沿用 nextstep.draft 与 nextstep.records；新增可选 activities 数组保存本次运动明细。旧记录和草稿保留。计划训练也可以添加额外动作和运动；只有实际完成力量组的混合计划训练才计入计划完成。原有单独运动补记入口继续保留，无正在进行的训练时单独保存；有草稿时加入当前训练。历史编辑支持修改本次运动时长、体重及距离，不将分项时长加到整次训练时长。

验证：60 项 Node 业务回归测试与 JavaScript 语法检查通过；隔离来源的真实 Edge 浏览器检查 320、390、1280 像素下的混合训练、刷新续练、结束保存、详情、历史编辑和统计切换，页面与弹窗无横向溢出。网页改动尚未重新打包 APK，未进行安卓真机验证。

## 训练项目快速查找（网页）

添加自由动作、替换当前动作、运动录入三个入口新增搜索结果列表。力量动作可按名称、部位、器械或记录类型搜索，多个关键词以空格分隔，例如「哑铃 背部」；同时可按器械筛选。运动支持按类型筛选，并可用「跑步」「楼梯」「走路」等日常名称查找现有活动。

最近完成的动作和已记录的运动优先显示，包括本次训练已完成的项目；未完成组不作为最近使用依据。列表在局部滚动区域内展示，点击项目后自动填写动作类型与重量参考，或选择运动强度并更新热量预览。搜索与筛选只更新结果，不清空组数、次数、时长等表单值，也不保存新记录。无匹配力量动作时仍可填写自定义名称，原动作下拉入口收在「全部动作 / 自定义」内。

验证：66 项 Node 业务回归与语法检查通过；真实 Edge 浏览器验证 320、390、1280 像素的关键词搜索、分类、点击选择、输入保留、焦点、最近排序、替换保留完成组、运动热量、自定义录入和最终保存，无页面或弹窗横向溢出。尚未重新构建 APK，未进行安卓真机验证。
